## 基板の構成

| 項目 | 内容 |
|---|---|
| 外形 | 170 × 130mm、M3 取付穴 4 か所（四隅から 4mm） |
| 層 | 4 層。表・裏 = 信号（空きは GND ベタ）、内層 2 枚 = GND（GND1・GND2） |
| 部品 | 242 点、すべてリード部品（表面実装なし） |
| 配置 | 機能ブロックごとの区画の中で、配線長が短くなるように自動配置（`tools/place.py`）。固定は DC 入力・ANT・リレー・RD16HHF1 だけ |
| 配線 | Freerouting 1.9.0。線幅: 13.8V 系・PA 出力 1.2mm、電源 0.6mm、RF 0.5mm、ほか 0.3mm |

区画（上辺 = 後面、下辺 = 前面）:

| 区画 | 範囲（mm） |
|---|---|
| 電源 | 左上 0〜40 × 0〜46 |
| 送信RF | 上段 40〜170 × 0〜46（左から BPF → 2N3866 → RD06HHF1 → RD16HHF1 → LPF → リレー → ANT） |
| 逓倍 | 0〜52 × 46〜82 |
| セラゾイド変調 | 52〜112 × 46〜82 |
| 受信 | 右列 112〜170 × 46〜130 |
| 制御 | 左下 0〜56 × 82〜130 |
| 送信音声 | 56〜112 × 82〜130 |

## 確認した項目

- 回路図との一致（DRC の schematic parity）: 食い違いなし
- 13.8V（最大 約 2.5A）の線幅 1.2mm: 外層 1oz で約 3A（温度上昇 10℃）まで
- GND: 内層 2 枚のベタで全 GND パッドがつながる。表・裏のベタは熱的接続（サーマル）で 1 本以上（`kicad/Serrasoid_TRX.kicad_dru`）
- RD16HHF1（Q6）は上辺（後面）に、タブを外側に向けて配置
- RD06HHF1（Q5）と放熱器 HS1（20PB020）は PSN_TRX と同じ位置関係
- アンテナ系: J5（ANT）→ K1（リレー）は基板の右上角で短い（ANT 29mm、TX_OUT 48mm）

## 気になる点（製造前に確認・手直しを検討）

| 項目 | 内容 |
|---|---|
| 長い線 | DRV_D（RD06HHF1 のドレイン → RD16HHF1 入力の結合 C）82mm、CLK0 71mm、CLK1 73mm、PM_OUT 58mm、RAMP 53mm。29MHz の波長（約 10m）に比べれば短く電気的には問題ないが、PA 出力と入力系の結合を避けるため、KiCad で目視確認したい |
| RD16HHF1 の取付 | タブは基板端から約 1mm 内側。シャーシの放熱器に当てるには、基板端とタブの位置関係をケースと合わせて決める必要がある |
| L7808・L7805 の放熱 | 縦置き TO-220。小型放熱器（クリップ式など）を付ける空間があるか要確認 |
| シルク | 部品番号の文字の重なり 19 か所（実装には影響しない） |
| 受信部の並び | 自動配置のため、LM386（低周波）が RF 部の近くに来ている。発振・回り込みが出るようなら離す |

## 配置の試行

送信の主要部品（BPF・2N3866・RD06HHF1・トランス）と受信の主要部品も固定して一列に並べる案を試したが、配線長の合計が増え、未接続が 2〜3 本残ったので採用しなかった（`tools/gen_pcb.py` の `fixed_positions` のコメント参照）。

# 基板チェック（第 2 回: Ver 1.1、第 1 混合を NJM2594V に変更して作り直し）

- 実施日: 2026-10-16
- 対象: `kicad/Serrasoid_TRX.kicad_pcb`（`tools/gen_pcb.py` → `tools/route.sh`。部品番号は回路図の位置順）
- 結果: **DRC エラー 0、未接続 0、回路図との食い違い 0**。警告はシルク（文字の重なり 33・銅箔上 10・基板端 4）のみ

## 変更点

| 項目 | 内容 |
|---|---|
| 部品 | 253 点（＋取付穴 4・放熱器 HS1）。第 1 混合 U13 を SA612AN（DIP-8）から **NJM2594V（SSOP8、0.65mm ピッチ、表面実装）** に。10.7MHz 増幅（Q6 2SC1815 ほか 10 点）を追加 |
| 表面実装 | U13 だけ（部品面）。`gen_pcb.py` は NJM2594V 以外の表面実装パッドがあると止まる |
| U13 の GND | 4 番から外側へ 1.8mm の線とビアで内層の GND へ（`tools/pcb_smd_gnd.py`。0.65mm ピッチのパッドの間には外層の GND ベタが入らない）。8 番（内部で未接続）は開放 |
| +5VA の線幅 | 0.6 → **0.3mm**（約 25mA。0.6mm では U13 のパッドに隣のパッドとの間隔 0.25mm を取ってつなげない） |
| 配置 | ミキサー出力 → 10.7MHz 増幅 → 水晶フィルタのネットの重みを大きくし、1 か所にまとめた（U13〜Q6 16.6mm、Q6〜FL1 12.1mm） |
| 上辺の部品禁止 | ケースの RD16HHF1 用放熱器のベースが基板の上辺に 1.1mm かかるので、RD16HHF1 の左右（放熱器の幅）の上辺から 1.6mm には部品を置かない（HS1 は上辺から 3.25mm） |
| 配線 | Freerouting 1.9.0 のあと、残った未接続は `tools/fix_route.py`（表・裏 2 層の格子で探して引く。間隔 0.25mm）で引く。今回は CLK1 と C74 の短い線が重なっていたので消して引き直した |

## 製造前に確認すること

- U13（SSOP8）のパッド寸法は KiCad 標準の TSSOP-8_4.4x3mm_P0.65mm（JRC の SSOP8 は本体 3.5 × 4.4mm、足先 6.4mm で同じ寸法）
- 10.7MHz 増幅の入出力の線が近くを通っていないか（発振しないか）、KiCad で目視
